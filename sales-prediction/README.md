# My First Machine Learning Project: Sales Prediction

## 📋 Project Overview
This is my first machine learning project that predicts sales based on advertising spend, product price, and holiday seasons.

## 🎯 What I Learned
- Data analysis with pandas
- Data visualization with matplotlib
- Machine learning with scikit-learn
- Linear regression models
- Model evaluation and prediction

## 📊 Dataset
The dataset contains:
- Advertising budget
- Product price  
- Holiday flag (1 for holiday, 0 for normal)
- Actual sales (target variable)

## 🚀 How to Run
1. Install requirements: `pip install pandas matplotlib scikit-learn joblib`
2. Analyze data: `python notebooks/analyze_data.py`
3. Train model: `python notebooks/train_model.py`
4. Make predictions: `python notebooks/predict_sales.py`

## 📈 Results
The model achieves ~90% accuracy in predicting sales based on input features.
